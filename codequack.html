Project CodeQuack
Category Development
Year 2025

Project Overview

CodeQuack is a gamified programming learning platform designed to make learning C++ and Python easier, more interactive, and engaging for beginners. The platform combines structured lessons, interactive quizzes, coding games, and personalized progress tracking to create an enjoyable learning experience. It incorporates gamification features such as XP points, levels, badges, streaks, and leaderboards to motivate learners and encourage consistent practice. It also includes Q&A support, responsive design for web and mobile devices, and a certification system to recognize learners' achievements upon course completion.

My Role

Developed the CodeQuack web application, focusing on responsive UI/UX, backend functionality, Firebase integration, and core features including authentication, lessons, quizzes, gamification, progress tracking, Q&A, and PDF certification.
