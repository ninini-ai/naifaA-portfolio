# Personal Portfolio Website

A responsive personal portfolio starter inspired by the reference design. Built with HTML, CSS and vanilla JavaScript.

## How to run
1. Extract the ZIP file.
2. Open the `creative_portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Customize before publishing
- Search for `Your Name` and replace it with your name.
- Change `YN` in the logo to your initials.
- Replace `hello@example.com` with your email address.
- Replace `https://github.com/` with your GitHub profile.
- Replace `#` links on project cards and social icons with real project/profile links.
- Add your own portrait at `images/profile.jpg`.
- Add real project screenshots and update the project descriptions.
- Add your CV at `assets/your-cv.pdf` (create the `assets` folder first), or remove the Download CV button.
- Edit the CSS variables at the top of `css/style.css` to change the color palette.

## Publish with GitHub Pages
1. Create a public GitHub repository named `yourusername.github.io`.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select `main` and `/ (root)`, then Save.
6. Wait for the published URL to appear in the Pages section.

The page uses Google Fonts and Lucide icons from CDNs, so those details need an internet connection.
